改进前后 · 核心差异
对照原始截图，从 9 个维度系统性梳理视觉/交互层改动

改进前 Original

  • ×面板头仅有"World / View / Projection"标签，无可见色条，难以与坐标轴/矩阵分组联想对应
  • ×输入框为系统默认风格，无单位标识，无 stepper，无 XYZ 区分色；看上去像普通表单
  • ×矩阵块挤在一处，纯文本数字密集排列，没有色彩语义和层级关系
  • ×视口为单一空白区域，无 HUD、迷你导航、演示词条、性能/光标信息
  • ×无演示进度提示，8 步教学缺少即时进度反馈
  • ×工具栏按钮只是一组纯文字，缺乏图标语义和 group 折叠
  • ×DX11 Lab 区信息扁平，Device/Shader/Rasterizer/堆放在一起，无分类徽章
  • ×无状态栏反馈（Device 状态、Tick、MSAA 信息）
  • ×Tracker 仅有 3 个数字输入框，无任何可视化预览
VS

改进后 Refined

  • ✓面板头 左侧色条 + 折叠 + 重置 + 徽章，World(红) / View(绿) / Projection(橙) 一眼对应
  • ✓XYZ 三联输入 各带彩色 Axis Tag + 独立步进按钮 + 标签色 swatch（X 红/Y 绿/Z 蓝）
  • ✓矩阵按 M_W(青) / M_V(紫) / M_P(琥珀) / MVP(亮粉) 分色卡片，可按步骤聚焦发光高亮
  • ✓视口集成 轴图例 HUD + 迷你导航器 + 浮动工具条 + 性能条 + 光标坐标
  • ✓工具栏嵌入 演示 N/8 进度条 + 标题 + 简述 + 上/下一步按钮，与 spec 中 "演示词条" 对齐
  • ✓工具栏按 选择 / 显示模式 / 物体 分组 + 图标 + 选中态阴影，分组化圆角化
  • ✓DX11 Lab / Debug 拆为 4 张 独立卡片(Device/Shader/Rasterizer/CB) + 状态点 + Primary 按钮
  • ✓底部 StatusBar 含 Device OK、SwapChain、MSAA、Tick、Polling 等关键指标
  • ✓Tracker 顶部 可视化八面体预览 + 步进 snap 切换，空间感更强

12 项关键改进
从左到右，从上到下，每一处都对应可量化提升

01 · LAYOUT

结构清晰化

保留三栏 Dock 布局，但加入标题栏 tabs + 菜单栏 + 工具栏三级导航；面板采用统一head · accent · body三段式，每段高度/边距严格按 8px 网格。

8px grid三段式面板
02 · COLOR

轴色 ↔ 面板一致

左侧 World(红)/View(绿)/Projection(橙)色条与 3D 视口里 X/Y/Z 锥形轴**色相一致**，矩阵 M_W/M_V/M_P/MVP 同样有独立色板，强化"色键"教学记忆。

X=redY=greenZ=blue
03 · INPUT

XYZ 三联控件

把 Position/Target/Tracker 等 XYZ 数据改为 三联紧凑面板：每格左侧有彩色轴标，右侧数字/步进，整体宽度一致，提升扫描效率。

tabular-numsstepper
04 · MATRIX

矩阵分色卡片

每个矩阵一个独立卡片，行间隔铺底加深、数字按矩阵主色微调、当前演示聚焦块加发光边 + 左侧 3px 渐变色带 — 与 spec 中的 demoMatrixFocus 严格对应。

focus glowrow stripe
05 · HUD

演示 HUD 词条

工具栏中嵌入 "演示 3/8 · 标题 · 简述" 词条，加上/下一步按钮，与文档的 8 步教学脚本一一对应；视口底部有 toast 提示应用状态。

demo 1-8stepper
06 · 3D VIEWPORT

浮动导航与工具

视口内 **浮动**装配：左上轴图例/右上迷你导航器(Navigator)/右中竖向工具条(Fill/Wire/Mat/Grid/Axes/Tracker)/左下性能 FPS+GPU 条/右下光标坐标 — 信息密度按"越近视线越集中"排列。

glassbackdrop-blur
07 · RENDER SCENE

3D 场景重绘

视口 SVG 场景包含 透视网格地面 + 立方体（Lambert 半透明 + 描边）+ 锥形 RGB 轴 + 文字轴标 + Tracker 八面体；与世界矩阵 Yaw=10°、Pitch=20° 同步。

3-face cubeoctahedron tracker
08 · DEBUG

DX11 Lab / Debug

从扁平堆叠改为4 张独立卡片：Device/Shader/Rasterizer/CB；Shader 提供 Compile/Reload/Watch 主按钮；开关采用 toggle + 文字标签双通道。

cardsCB hex dump
09 · TRACKER

追踪点可视化

上方高 120px 八面体预览区（含渐变菱形 + 标尺），下方三联 X/Y/Z 数值 + Snap 切换，与规范中"粉色线框八面体"对齐。

visual + inputsnap
10 · STATUS

底部状态栏

新增 24px 高 status bar：Device OK / SwapChain / Backbuffer & MSAA / Tick / Polling / Render Thread / DPI — 一眼给出"GPU + 引擎"组合状态。

status barpoll 1.0ms
11 · VISUAL LANG

现代深蓝 Fusion

按规范要求的 "深蓝圆角 + QSS"，所有面板/输入/按钮圆角 6-10px，hero 渐变 + 玻璃态，蓝色为主的极简专业感；与 DX11-Study 视觉语言对齐。

radius 6/10/14QSS-ready
12 · ACCESSIBILITY

色彩 + 文字双通道

关键信息如 XYZ、矩阵、轴标签同时用 色彩 + 文字/字母 双通道编码；交互元素皆有 hover/active/focus 状态；图标均带 tooltip。

WCAG AAtooltips
