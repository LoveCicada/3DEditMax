# 3DEditMax UI 重构设计方案

> 面向 Qt + DX11 的 3D 教学编辑器（DX11-Lab-Study）
> 设计依据：`docs/superpowers/specs/2026-08-16-dx11-lab-teach-design.md`

---

## 1. 设计目标

围绕设计文档中的两条教学主轴进行 UI 升级：

- **坐标轴彩色编码**：世界轴 X/Y/Z 分别使用 红 / 绿 / 蓝，贯穿 3D 视口与面板配色。
- **矩阵分色看板**：四个矩阵（`M_W` / `M_V` / `M_P` / `MVP`）各配一个专属色键，用于面板高亮与演示聚焦。

原始界面粗糙、扁平、缺乏层级与信息组织，本次重构使其更专业、更现代、更适合课堂教学演示。

## 2. 视觉语言

### 2.1 配色体系（深蓝 Fusion 风）

| 用途 | 色值 |
|------|------|
| 背景三层分段 | `#0E1320` → `#161B2B` → `#1D2335` |
| 主色（强调蓝） | `#4CC9F0` 青 |
| 辅助强调 | `#3A86FF` 蓝 |

### 2.2 矩阵色键

| 矩阵 | 色值 | 语义 |
|------|------|------|
| `M_W`（World） | `#4CC9F0` 青 | 世界矩阵 |
| `M_V`（View） | `#B388FF` 紫 | 视图矩阵 |
| `M_P`（Proj） | `#FFB703` 琥珀 | 投影矩阵 |
| `MVP` | `#F72585` 亮粉 | 组合矩阵 |

### 2.3 轴色编码

| 轴 | 色值 |
|----|------|
| X | 红 `#F72585` / `#FF4D6D` |
| Y | 绿 `#2DC653` / `#4CC9F0` |
| Z | 蓝 `#3A86FF` / `#4361EE` |

### 2.4 形态语言

- **圆角体系**：`6px / 10px / 14px` 三档，符合 QSS 可直接落地。
- **不透明度与辉光（glow）**：营造现代编辑工具质感，对齐 DX11-Study 风格。
- **三段式分层背景**：从深到浅递进，突出视口主区域。

## 4. 各区域设计要点

### 4.1 面板头（三段式）

每个矩阵面板头部统一采用三段式结构：

```
[左侧色条] [标题] [徽章]  [折叠/重置按钮]
```

- 左侧 3px 色条 + 面板头底色微染，按矩阵色键着色。
- World 红 / View 绿 / Proj 橙 —— 与 3D 轴色一一对应，强化"色键记忆"。

### 4.2 3D 视口（DX11 Swapchain 之上的非原生 HUD）

| 位置 | 元素 |
|------|------|
| 左上 | 轴图例 HUD（X / Y / Z / T） |
| 右上 | 迷你导航器 Navigator（相机视锥 + 三轴） |
| 右中 | 浮动竖向工具条（实体 / 线框 / 材质 / 网格 / 轴 / 追踪点） |
| 左下 | 性能条：FPS + MS + GPU + VRAM + Draws |
| 中下 | 玻璃态 Toast（演示应用反馈） |
| 底部 | 状态 pill：MSAA / Vsync / 材质 / 剔除 / Depth / 演示模式 |

3D 场景内容：

- 透视网格地面
- 锥形 RGB 轴（X 红 / Y 绿 / Z 蓝）+ 轴标文字
- 半透明 Lambert 立方体
- 粉色八面体追踪点（Track Point）
- 世界轴平移手柄（符合 spec 的 follow-up 例外）

### 4.3 演示 HUD（符合 spec 中"演示词条"）

- 工具栏嵌入演示词条：`演示 3 / 8 · 标题 · 简述`
- 上一步 / 下一步 按钮
- 矩阵 `M_V` 按 `demoMatrixFocus` 发光聚焦：
  - 左侧 3px 渐变色带
  - 蓝色 glow 边框

### 4.4 DX11 Lab / Debug 区

- 从扁平堆叠 → 4 张独立卡片：

| 卡片 | 内容 |
|------|------|
| Device | 设备状态、特性级别 |
| Shader | 着色器编译 / 绑定状态 |
| Rasterizer | 光栅化状态 |
| CB（常量缓冲区） | 16 进制常量缓冲区值展示 |

### 4.5 底部状态栏（新增）

一眼给出"引擎 + GPU"组合状态：

```
Device OK · SwapChain · Backbuffer · 4×MSAA · Tick · Polling · CB Upload · DPI
```

## 6. 改进点速览

| 原问题 | 改进后 |
|--------|--------|
| 配色扁平、无层次 | 三段式深蓝分层 + 辉光质感 |
| 面板无信息层级 | 三段式面板头 + 色键徽章 |
| 矩阵无视觉关联 | 四矩阵专属色键，演示时发光聚焦 |
| Debug 信息堆叠 | 4 张独立卡片 + CB 十六进制展示 |
| 缺少引擎状态反馈 | 新增底部状态栏 + 视口性能 HUD |
| 无教学演示引导 | 工具栏演示词条 + 上/下一步控制 |
