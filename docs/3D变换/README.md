# 3D 变换矩阵交互讲解

可离线打开的单页教程：把模型矩阵、世界矩阵、视图矩阵、投影矩阵讲成「四次搬家」，并对照 3DEditMax 实验台。

## 怎么打开

用浏览器直接打开本目录的 [`index.html`](index.html)。不需要本地服务器，也不需要联网（无 CDN、无外部字体）。

每章结构相同：**一句人话 → 可播放示意图 → 4×4 矩阵 → 和实验台的关系**。

示意图均可点「播放 / 暂停」。暂停后用滑块自己拖。拖动该图上的滑块也会暂停自动演示。

## 约定

与 3DEditMax 相同，避免和网上 OpenGL 列向量文章打架：

- Direct3D 11 **左手系**，Y 向上，Z 向前（远离相机为正深度）
- 顶点按**行向量**相乘：`p' = p × W × V × P`
- 世界矩阵：`W = S * R * T`（先缩放、再旋转、再平移），对应 `BuildWorld` 的 `return s * r * t;`
- 投影后 NDC：x、y ∈ [-1, 1]，z ∈ [0, 1]

## 八章与七个交互动画

| 章 | 讲什么 | 示意图 |
|----|--------|--------|
| 1. 顶点流水线 | 粉点依次走过模型 / 世界 / 视图 / 投影 / 屏幕 | 空间车站动画 |
| 2. 五种空间 | 拖模型点，五个坐标卡片一起刷新（对应 `TrackPoint`） | 淡色立方体 + 世界立方体 + 追踪点 |
| 3. 模型矩阵 | 网格坐标永远写在物体自己的「身体」里 | 与五种空间同一套场景 |
| 4. 世界矩阵 | TRS 滑块；行星–卫星演示局部矩阵 vs 世界矩阵 | 立方体 TRS；公转卫星 |
| 5. 视图矩阵 | 左：相机在场景里转；右：世界被搬到相机面前 | 分屏；`V = inverse(CameraWorld)` |
| 6. 投影矩阵 | 视锥压成 NDC 盒子，可切透视 / 正交 | 左视锥、右 NDC |
| 7. WVP | 合成矩阵 + HLSL `mul(float4(pos,1), worldViewProj)` | 教学相机视口 + 五空间数字 |
| 8. 对照实验台 | 网页概念桥接到实验台面板与源码 | 无单独动画，见对照表 |

行向量下卫星世界：`W_卫星 = Local_卫星 × W_行星`（先相对行星，再跟着行星进大厅）。本仓库第一期没有场景图，物体的 World 就是它的 TRS，实验台只暴露 World。

## 对照实验台

| 网页这一章 | 实验台里看哪里 | 源码 |
|------------|----------------|------|
| 模型空间 / 追踪点 | 追踪面板的模型坐标，视口品红标记 | `TrackPoint` |
| 世界矩阵 TRS | Transform 面板的平移 / 欧拉 / 缩放 | `BuildWorld` → `s * r * t` |
| 视图矩阵 | 视口轨道旋转、滚轮距离 | `BuildView` → `XMMatrixLookAtLH` |
| 投影矩阵 | 透视 / 正交、FOV、near、far | `BuildProjection` |
| WVP | 矩阵看板与 Constant Buffer 观察 | HLSL `mul(pos, worldViewProj)` |

建议顺序：先在本页把「房间」看熟，再打开实验台——只动 Transform，看世界矩阵变；只转视口，看视图矩阵变；只改 FOV，看投影矩阵变。

实验台看板默认按**列主序**显示（与 HLSL 上传一致）；本页表格按**行主序**画出行向量习惯。切换行列开关只改字符串，不转置 GPU 数据。
