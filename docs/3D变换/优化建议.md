## 一、最该补的 4 个「认知缺口」

这些是让小白「卡住就过不去」的地方，现有版本只有文字解释，没有可视化补刀。

### 1. 透视除法的本质：`w` 是「距离分母」

当前第 6 章只展示「视锥被压成 NDC」，但**为什么除以 w 能近大远小**是入门者最大的疑问。

- `drawFrustum` 右窗改为「先把视锥 8 个角除以各自的 w」的逐步动画：每个角挂一条小尾巴，从视锥角飞到 NDC 角；远面角因 `w` 大、被压得更靠中心——这就是透视。
- 「裁剪空间」卡片旁边加独立的「**w 值卡片**」，展示原 `w` 与除以后的 `x/w, y/w`，让「w 是个分母」肉眼可见。

### 2. 齐次坐标里 `w=1` 与 `w=0` 的差异

教材级内容：**位置用 `w=1`、方向向量用 `w=0`**（平移不影响向量）。当前完全没提。

- 第 4 章「世界矩阵」加「**面的法线经过 W 之后会怎样**」附图：画出立方体 6 条法线，对比位置（`w=1`，跟随平移）与法线（`w=0`，只旋转）。
- 加隐藏开关「显示法线」：看到「旋转后法线仍垂直表面，平移不会弄歪它」。

### 3. 矩阵乘法**不**可交换

TRS 滑块只看合成结果，小白容易疑惑「先平移再旋转 ≠ 先旋转再平移」。README 写了 `W = S * R * T` 是约定，但没有让用户感受差异。

- 第 4 章加 **TRS 顺序实验台**：按钮 `S·R·T / R·S·T / T·R·S / R·T·S` 切换，同一输入得到不同结果（非均匀缩放下法线更明显）。
- 配一句人话：「顺序可以调，但**约定必须一致**——CPU 和 HLSL 看到的是同一张。」

### 4. `LookAtLH` 三向量是怎么算出来的

`math.js` 注释有 `xaxis = up × zaxis; yaxis = zaxis × xaxis`，但**代码是黑盒**。

- 第 5 章右窗加三根箭头：红 forward、蓝 right、绿 up，标注「right 是世界 up 与 forward 的叉乘」「up' 是 forward 与 right 的叉乘」。
- 帮助学生读源码 `BuildView`。

## 二、教学结构改进：先 2D 再 3D

当前八章直接进入 3D 矩阵与视锥，对零基础门槛过高。建议在现第 1 章之前加「过渡章」：

### 0. 二维热身

- 2D 点仿射变换：`p' = p·T`、`p' = p·R`、`p' = p·S`。
- 一句话点透：3D 就是「再加一行一列 + 透视除法」。
- 作为「为什么是 4×4」的铺垫。

> 受众是小白时，2D 跳 3D 的落差必须填平，否则第一章的「流水线」对没接触过矩阵乘法的人很突兀。

## 三、可视化补强（按章）

### 第 1 章 · 流水线

- 5 个站点目前等距静态，粉点只上下跳。改进：
  - 粉点进入站点时，站点下方浮现对应矩阵公式（迷你版 `W`/`V`/`P`）。
  - 站点间用数学符号链起来：`p_model ─[×W]→ p_world ─[×V]→ p_view → …`。

### 第 2 章 · 五种空间

- 5 张坐标卡是数字，但「点」和「立方体」分离显示。改进：
  - 各空间的小立方体叠加在主画面（模型立方体在模型空间正中、世界立方体在世界空间），5 个房间**同框共存**。
  - 追踪点拖滑块时画**残影拖尾**，让 3D 路径更直观。

### 第 3 章 · 模型矩阵

- 「模型矩阵 = 父物体的相对变换」是纯文字。改进：
  - 加迷你演示：拖滑块改模型自身坐标，另一面板显示相对父（这里是世界）的偏移。
  - 或加章节小测验：「在身上的口袋挖个洞，世界里的口袋会变吗？」（答案：不会）

### 第 4 章 · 世界矩阵

- 4×4 表无引导。改进：
  - 滑块变化时对应矩阵单元**高亮闪烁 0.5 秒**（CSS `box-shadow` pulse），植入「格子由滑块决定」的关联感。
  - TRS 顺序实验（见第一节建议 #3）。
  - 「模型 vs 世界」比较卡配**同框图**：左边父子节点树，右边行星卫星绕转。

### 第 5 章 · 视图矩阵

- 双窗对比好，但「为什么 V = inverse(CameraWorld)」没有可视化印证。改进：
  - 左窗画相机世界坐标系三轴 + `V⁻¹`（`camW` 矩阵），让用户看到 V「反着」把世界搬过来。
  - 「距离」滑块变化时，画 **eye → target 箭头**，拖动时眼睛沿它移动。

### 第 6 章 · 投影

- 现有 `squeeze` 内插过渡动画可保留，但教科书级展示是**角点一一对应的射线**。
- 改进：每个角画一条虚线，从视锥角延伸到对应 NDC 角，一眼看出「近端外推多、远端外推少」。
- 在右侧 NDC 盒子标签**显式写出** DX `z ∈ [0,1]` vs GL `z ∈ [-1,1]` 的差异，避免对照 GL 教程困惑。

### 第 7 章 · WVP

- 补充：
  - W / V / P / WVP 四张矩阵并排，滑块一动对应单元同时闪烁。
  - 视口保留追踪点，让小白看到「粉线从模型到屏幕就是课本示意图」。
  - 内嵌 HLSL 片段（纯展示）：
    ```hlsl
    float4 posWS = mul(float4(pos, 1), world);
    float4 posVS = mul(posWS, view);
    float4 posCS = mul(posVS, proj);
    o.pos = float4(posCS.xy / posCS.w, posCS.z / posCS.w, 1);
    ```
    与行向量 `p × W × V × P` 图对照。

### 第 8 章 · 对照实验台

- 「源码」列只有函数名，对小白没用。改进：
  - 贴 8–12 行 DirectXMath 实际片段（从 `src/teach/Transforms.cpp` 截），让网页直接成为源码导读。

## 四、交互与可玩性

1. **重置 / 预设按钮**
   - 每个有滑块的可视化加「重置」键，参数归默认值。
   - 加「常见预设」下拉：「等距 / 高俯视 / 仰视 / 切片」。

2. **导出当前矩阵为代码片段**
   - 4×4 表右上角加「复制 HLSL / GLSL / JSON」按钮。
   - 学生改完滑块，直接 copy 到自己的 shader 验证，闭环。

3. **行 / 列主序切换**
   - 8 章末尾「看板默认按列主序」是文字说明。在矩阵表上加「**行主序 ⇄ 列主序**」切换按钮，切换瞬间转置显示。

4. **数值联动动效**
   - 滑块拖动时，5 坐标卡与 4×4 表中**变化的数字**短暂高亮（CSS `transition: background 0.5s` + class 切换）。当前 `syncOutputs` 直接覆写 `textContent`，无过渡。

5. **鼠标拖拽相机**
   - 给可视化解锁「按住左键拖动旋转相机、滚轮缩放」——DCC 软件的基本直觉，与实验台视口体验一致。目前全部靠滑块，体验脱节。

## 六、视觉 / UI 微调

- **目录锁定高亮**：TOC 高亮加一道「当前章进度条」在左侧固定列。
- **滑块配色随矩阵**：`W` 章用青滑块、`V` 章用紫、`P` 章用琥珀——颜色带出章节色彩一致性。
- **矩阵单元 hover 显示公式来源**：`m12` hover 时弹出「`tx`：X 平移，由左侧平移滑块决定」。
- **章节内联导览**：每章顶部 2 行总结「这一章你会得到什么」，不用读完四段话才知道重点。
- **可访问性**：补键盘导航 + ARIA。当前 `aria-label` 仅一处；目录、按钮、滑块都要补。
