# Superpowers working notes

本目录记录 Subagent-Driven Development（SDD）过程中的任务简报、实现报告、评审 diff 与进度账本，便于本地与远程追溯。

| 路径 | 用途 |
|------|------|
| `sdd/progress.md` | 任务完成账本 |
| `sdd/task-N-brief.md` | 从实现计划抽出的单任务要求 |
| `sdd/task-N-report.md` | 实现/验收报告 |
| `sdd/review-*.diff` | 任务范围评审用的 git 包 |

后续抛光或新阶段可继续往 `sdd/` 追加同名约定文件。
